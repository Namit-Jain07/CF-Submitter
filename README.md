# CF-Submitter

A lightweight extension that automatically captures the problem code from Codeforces problem pages and pre-fills it on the submission page when you navigate to it.

## How to Install

1. Click the green **Code** button at the top right of this page and select **Download ZIP**.
2. Extract the downloaded `.zip` file anywhere on your computer.
3. Open Google Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** by toggling the switch in the top-right corner.
5. Click the **Load unpacked** button in the top-left corner.
6. Select the extracted folder (the one containing `manifest.json`).

Now, browse any problem on Codeforces, hit the submit tab, and enjoy seamless autofilling!
